# Figures – how the line diagram evolved

All files are regenerated by `python src/make_figures.py`.

| # | File | What it shows | Why the next step |
|---|---|---|---|
| 01 | `01_graphviz_placeholder14.pdf` | First placeholder selection of 14 broad sports (athletics, swimming, cycling, rowing, canoeing, gymnastics, judo, wrestling, boxing, fencing, shooting, weightlifting, taekwondo, sailing), Graphviz default layout: **269 concepts** | Too many concepts; broad sports combine freely |
| 02 | `02_graphviz_final13.pdf` | Final selection of 13 sports in three generations (since 1896 · 1964/2000 · 2020/24): **125 concepts**, Graphviz layout | Graphviz knows nothing about the order structure: wide tangle, hard to read |
| 03 | `03_additive_pure.pdf/.png` | Additive layout: each sport is a vector, a concept sits at the sum of its sports' vectors; height = number of sports; classic sports point left, new sports right | Different concepts land on the same point; labels collide |
| 04 | `04_additive_spread.pdf/.png` | Additive order kept, nodes spread per level to a minimum distance | Readable, but the full picture is still dense: 125 concepts |
| 05 | `05_interactive.html`, `05_interactive_gold.html` | Interactive version of 04: select sports/nations, shows B′/B″ and A′/A″, highlights the corresponding part of the lattice, exports the current view as SVG. Gold-only variant: 47 concepts | Used for reading the findings and for highlighted figures in the report |
